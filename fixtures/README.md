# Fixture packages

Valid Hippo capture packages (major 1; packages 1 to 6 are format 1.0, package 7 is format 1.1, and its server enrichment is format 1.2) for building and testing a reader. Generated by `swift run --package-path HippoKit hippo-fixtures fixtures/packages`; do not edit by hand. Validate with `scripts/validate-fixtures.sh`.

Packages live at `fixtures/packages/captures/2026/11/07/<capture-id>/`. Clock, time zone (`America/Los_Angeles`) and IDs are fixed; capture N was taken at 2026-11-07T17:0N:00Z. Media file bytes (PDF, video, audio) embed creation timestamps, so regenerating changes their hashes. Commit regenerated output as a whole. Packages 1 to 6 are frozen as format 1.0 and must stay byte-identical: do not run the default mode again. Package 7 is written by its own mode (below), which is byte-stable.

| Name | Capture ID | Method | Content types |
|---|---|---|---|
| `text-note` | `00000000-0000-4000-8000-000000000001` | typed_note | text |
| `url-only` | `00000000-0000-4000-8000-000000000002` | share_extension | url |
| `image` | `00000000-0000-4000-8000-000000000003` | share_extension | image |
| `mixed` | `00000000-0000-4000-8000-000000000004` | share_extension | image, pdf, url |
| `video` | `00000000-0000-4000-8000-000000000005` | share_extension | video |
| `voice-recording` | `00000000-0000-4000-8000-000000000006` | voice_recording | audio |
| `context` | `00000000-0000-4000-8000-000000000007` | share_extension | image, audio |

- `text-note`: UTF-8 text attachment, no URLs.
- `url-only`: no attachments; the URL and shared title are in `metadata.json`.
- `image`: PNG whose embedded capture time has no UTC offset (`has_utc_offset: false`).
- `mixed`: PNG, JPEG (embedded time with offset, GPS, camera make/model), blank one-page PDF, one URL, and a user note. Also has two comments (see below).
- `video`: 1 s H.264 `.mov`, 64x48.
- `voice-recording`: 1 s AAC `.m4a`.
- `context`: format 1.1 (`schema_minor` 1). A user note, a PNG (1170 x 2532, a QR code for `https://example.com/hippo`), a 1 s silent AAC `.m4a`, a `capture_location` carrying all six extras (coordinates reused from `mixed`), and the five `context.*` observations (`car_audio` output "CarPlay", every device field, `wifi`, `previous_capture_id` of capture 6). All data is invented.

## Comments

The `mixed` package has two append-only comments under `comments/` (layout and rules in `docs/package-format.md`): `00000000-0000-4000-8000-00000000c001` (typed, "Bought this one.", added one hour after the capture) and `00000000-0000-4000-8000-00000000c002` (a 1 s AAC `.m4a` plus its json, added two hours after). Neither is listed in `complete.json`, so the package digest is the same as without them. Validated against `schema/capture-comment-v1.schema.json`.

## Enrichment fixtures

Derived data for the `url-only` capture, in the layout of `docs/enrichment-format.md`, under `fixtures/packages/enrichments/<layer>/2026/11/07/00000000-0000-4000-8000-000000000002/`. Generated by `swift run --package-path HippoKit hippo-fixtures enrichments fixtures/packages` (run after the packages exist; it never touches `captures/`). `package_digest` is the digest of that package's `complete.json`. Producer is `hippo-fixtures`, `generated_at` is fixed at `2026-11-07T18:00:00.000Z`.

| Layer | Facets |
|---|---|
| `device` (silver) | `link_preview` (title, site name, JPEG thumbnail in `assets/`), `source_app_guess` (Safari) |
| `server` (gold) | `summary`, `tags`, `link_preview` for the same URL with only a title (shows the field-by-field override) |

## Format 1.1 fixture

`swift run --package-path HippoKit hippo-fixtures context fixtures/packages` writes only package 7 (replacing it if present) and its device enrichment, `fixtures/packages/enrichments/device/2026/11/07/00000000-0000-4000-8000-000000000007/enrichment.json`, which holds all six new facet kinds (`motion_activity`, `weather`, `barcodes`, `language`, `sound_classification`, `screenshot`) with hand-built payloads: they are examples of the shapes, not detector output. Output is byte-stable: the PNG is drawn with fixed inputs, and the audio's creation timestamps are zeroed after it is written. Running the mode twice leaves `git status` unchanged. Tests: `legacyFixturesHaveNoMinor` and `contextFixtureCarriesEverySignal` in `HippoKit/Tests/CaptureCoreTests/FixtureTests.swift`.

The mode pins `schema_minor` 1 for package 7 and its device enrichment, whatever minor the app now writes, so rerunning it after a format bump still leaves them byte-identical.

## Format 1.2 fixture

`swift run --package-path HippoKit hippo-fixtures server fixtures/packages` writes only the server enrichment for package 7, `fixtures/packages/enrichments/server/2026/11/07/00000000-0000-4000-8000-000000000007/enrichment.json` (replacing it if present; run after package 7 exists, it only reads that package's `complete.json` for `package_digest`). It is format 1.2 (`schema_minor` 2), producer `hippo-fixtures`, `generated_at` `2026-11-07T18:00:00.000Z`, and holds `summary` and `tags` (provenance `server_model`) plus the four 1.2 kinds:

| Facet | Provenance | Data |
|---|---|---|
| `display` | `server_model` | title "Cafe menu with specials code", topic `food`, three weighted keywords |
| `image_description` | `server_model` | one item for the PNG, attachment `00000000-0000-4000-8000-000700000001` |
| `people` | `server_model` | one item, "Ana" from `user_note` |
| `circumstance` | `rules` | `in_car` (high), `in_a_burst` (medium), `daylight` (high), each with evidence |

The payloads are hand-built examples of the shapes, not model or rule output. "Ana" is invented: package 7's note names nobody, and the item only shows the shape of `people`. Output is byte-stable; running the mode twice leaves `git status` unchanged. Test: `serverFixtureCarriesEveryNewKind` in `HippoKit/Tests/CaptureCoreTests/FixtureTests.swift`.
