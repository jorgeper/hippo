# Hippo iPhone App (Plan 2 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An installable Hippo iPhone app and Share Extension on top of HippoKit. It covers capture (share, note, voice), the Timeline list with search and filters, capture details, settings and sync status with Retry, plus one-command device install. Dropbox comes in Plan 3; until then a debug-only "Developer folder" destination exercises sync end to end.

**Architecture:** All logic that can run without UIKit goes into two new Mac-testable HippoKit targets:
- `ShareIntake`: share payload → `CaptureDraft`.
- `HippoPresentation`: view models, formatting, provider registry, sync coordinator.

The iOS targets in `App/` stay thin: SwiftUI views plus the system services that only exist on iOS (AVAudioRecorder, CoreLocation, QuickLook, BackgroundTasks). The first three tasks close HippoKit gaps parked at the Plan 1 final review.

**Tech Stack:** Swift 6.4 (Swift 6 mode), SwiftUI, Observation, UniformTypeIdentifiers, AVFoundation/AVKit, CoreLocation, QuickLook/QuickLookThumbnailing, BackgroundTasks, XcodeGen, Xcode 27.2, Swift Testing (HippoKit) and XCTest UI tests (app).

**Spec:** `hippo-v0-spec.md` (base) + `docs/superpowers/specs/2026-11-07-hippo-v0-design.md` (wins on conflict). Executors read both. Plan 1 (`docs/superpowers/plans/2026-11-07-hippo-core.md`) defines HippoKit, which is merged on `main`.

**Branch:** `feat/hippo-app`, from `main`.

## Global Constraints

- iOS deployment target `27.0`; Swift 6 language mode; iPhone only (`TARGETED_DEVICE_FAMILY = 1`). `MARKETING_VERSION 0.1.0`, `CURRENT_PROJECT_VERSION 1`.
- Bundle and group IDs (exact):
  - app `com.jorgeper.hippo`
  - extension `com.jorgeper.hippo.share`
  - App Group `group.com.jorgeper.hippo`
  - keychain group `$(AppIdentifierPrefix)com.jorgeper.hippo.shared`

  Don't create any other App IDs, because the free team allows about 10 per 7 days.
- Store root: `<App Group container>/Library/Application Support/Hippo/`, giving `StoreLayout(root:)`. Intake temp files go under `<store root>/intake/`.
- `DEVELOPMENT_TEAM` is set **only** in the gitignored `Config/Local.xcconfig`. No team ID, device UDID or device name may appear in any committed file. The generated `Hippo.xcodeproj` is not committed.
- HippoKit targets import no UIKit, AppKit or SwiftUI and stay `swift test`-able on macOS. Only `App/` code may use UIKit, SwiftUI, AVAudioSession, CoreLocation, QuickLook or BackgroundTasks. No third-party dependencies anywhere.
- Copy:
  - Use "Captures", never "Inbox".
  - Sync labels are exactly *On iPhone*, *Synced* and *Needs attention*.
  - The success line is "✓ Saved on this iPhone".
  - Missing values are omitted, never shown blank or as "Unknown".
- Logs use `os.Logger(subsystem: "com.jorgeper.hippo", category: …)` with fixed strings only: no content, filenames, URLs, IDs, paths or precise location.
- The extension:
  - never loads file content into memory: file types use `loadFileRepresentation`, never data loading;
  - never waits for a location fix;
  - never shows sign-in UI;
  - never runs sync.
- `public.html` (and anything conforming to it) is never rendered; it's offered through Share/Export only.
- Use system fonts and colors only, with no fixed point sizes for text, so Dynamic Type and Dark Mode work.
- Every SQLite-touching operation in the app runs inside a background-task assertion, and the extension finishes its commit before `completeRequest`. This avoids `0xdead10cc` termination for holding a lock in a shared container while suspended.
- Commit after every task. Before each commit, run `git diff --cached` and read all of it for secrets (Jorge's global rule).

## Review Focus

1. **Big or slow shared items** (a 2 GB video, an iCloud-only photo that must download): the extension streams them to disk, shows progress, and Cancel leaves nothing behind. → Task 4 `fileTypesUseFileCopyOnly`, `discardRemovesIntakeDirectory`. Task 13 `cancelDiscardsIntake`.
2. **Huge shared text, or text that duplicates the shared URL**: text over 100,000 UTF-8 bytes becomes a `.txt` attachment, and duplicate text isn't stored twice. → Task 4 `largeTextBecomesAttachment`, `urlTextDuplicateNotRepeated`.
3. **Captures made in another time zone near midnight**: the row's day header uses the recorded local day, and its time uses the recorded UTC offset, not the phone's current zone. → Task 3 `summaryCarriesUTCOffset`, Task 5 `rowTimeUsesRecordedOffset`.
4. **Deleting something that hasn't uploaded, or is uploading right now**: the confirmation warns that this is the only copy, and the upload stops. → Task 6 `deletePromptWarnsWhenUnsynced`, `deletePromptForActiveUpload`.
5. **Location off, denied, stale or invalid**: the capture always saves, without a location. → Task 1 `invalidLocationIsDroppedWithObservation`, Task 8 `locationPolicyRules`.

### Task 2: Job lifecycle hardening (parked M5, M6, M1 residual)

**Files:**
- Modify: `HippoKit/Sources/SyncEngine/SyncWorker.swift`, `HippoKit/Sources/LocalRepository/JobStore.swift`, `HippoKit/Sources/LocalRepository/DestinationStore.swift`
- Test: `HippoKit/Tests/SyncEngineTests/SyncWorkerTests.swift`, `HippoKit/Tests/LocalRepositoryTests/DestinationJobTests.swift`

**Interfaces:**
- Produces:
  - `SyncWorker.leaseOwner: String` (public), equal to `"\(owner)#\(UUID().uuidString.lowercased())"` and fixed per instance. All JobStore calls use it. The `owner:` init/`makeWorker` parameter keeps its name and is now a prefix.
  - `JobStore.claimNext(owner:now:lease:reclaimDelay:)`, where `reclaimDelay: @Sendable (Int) -> TimeInterval` defaults to `JobStore.defaultReclaimDelay`, which is `min(21_600, 30 * 2^(n-1))` seconds.
  - `JobStore.clearCancel(captureID:)`: new behavior.
  - `DestinationStore.destination(id: String) throws -> Destination?`.

**Rules**
- **Reclaim (M6):** `claimNext` treats an `uploading` row with an expired lease as a crashed attempt, inside the same transaction:
  - It does `attempt_count += 1` and sets `last_error_code = 'lease_expired'`.
  - If the new count is `>= 3`, it sets `state = 'retryable_failure'`, `next_attempt_at = now + reclaimDelay(count)`, clears the lease, and moves on to the next candidate.
  - Otherwise it claims the row as before.
  - `SyncWorker` passes `{ RetryPolicy().delay(attempt: $0, retryAfter: nil, random: { Double.random(in: 0...1) }) }`.
- **`clearCancel` (M1 residual):** it also moves rows with `state = 'paused' AND last_error_code = 'cancelled'` back to `pending`, with `next_attempt_at = NULL`.

    - Worker B's `runOnce()` reports `idle`.

**Classification of each provider `i`, in order.** UTType comes from the identifier; unknown identifiers make dynamic types.
1. **Find a file type.** `fileType` is the first identifier that meets all of these:
   - it conforms to `.data`;
   - it does not conform to `.url` or `.plainText`;
   - it is not a rich-text equivalent (`.rtf`, `.rtfd`, `.flatRTFD`, `.html`) when the provider also offers plain text.
2. **If there is a file type:**
   - `copyFile` it to `directory/<i>.<ext>`, where ext is `preferredFilenameExtension`, else `bin`.
   - The attachment is `.file(url)`, `originalFilename: suggestedName` (verbatim), `uti: fileType`, `mimeType: preferredMIMEType`, `representationSource: "item_provider_file"`.
3. **Else, if the only URL type is `public.file-url`:** `loadURL()`. If it's a file URL, copy it the same way with security-scoped access, using the file's own type.
4. **Else, if it offers a non-file `.url` type:**
   - `loadURL()` becomes `CapturedURL(url: absoluteString, source: "shared_payload")`.
   - If it also offers plain text whose trimmed value differs from the URL string, keep that text.
5. **Else, if it offers plain text:** `loadText()`, and keep the text.
6. **Otherwise:** `IntakeFailure(i, .unsupported)`. Any thrown load becomes `.loadFailed`, and partial files are deleted.

**Assembly**
- `sharedTitle`: the trimmed title, nil if empty.
- **Texts:** `contentText` first, if it's non-empty and not equal to a kept text or URL. Join the texts with `"\n\n"`.
- **Large text:** if the joined text is over 100,000 UTF-8 bytes, it becomes `.data` attachment `uti: "public.utf8-plain-text"`, `mimeType: "text/plain"`, `representationSource: "item_provider_data"`, and `sharedText` is nil. Otherwise it's `sharedText`.
- **URLs:** deduplicated by string, keeping the first.
- `method: .shareExtension`. No location is set here.

**Observations** (provenance `"ns_extension_item"`)
- `share.registered_type_identifiers`: an array of arrays of strings, at most 32 per provider, each at most 200 characters.
- `share.suggested_names`: an array of strings or `.null`, each at most 255 characters.
- `share.userinfo_keys`: sorted key names (at most 20, each at most 100 characters), only when non-empty. Values are never recorded.

**Row rules** (metadata nil means use the summary only)
- **time:** `capturedAt` formatted `.shortened` (time only) in `TimeZone(secondsFromGMT: utcOffsetSeconds)`, else the current zone.
- **comment:** `noteExcerpt`.
- **Multi:** `attachmentCount >= 2` gives `.multi`, with up to 3 image/video attachment paths, and `extraCount = attachmentCount − shown`.

**Copy and rules**
- **`summary`:**
  - "{n} items · {size}" when there are several attachments;
  - a single attachment gives its filename, or "1 photo" / "1 video" / "1 file", then " · {size}";
  - a URL-only share gives the host;
  - text only gives "Text".
- **`destinationLine`:**
  - with a destination: "Saves on this iPhone first. Uploads to {destinationName} when it can."
  - with none: "Saves on this iPhone. Uploads once you connect Dropbox in Hippo."
- **Intake failures with content remaining:**
  - unsupported only: "Hippo can't save {n} of these items."
  - load failures only: "{n} items couldn't be copied."
  - both: "{a} items can't be saved and {b} couldn't be copied."

  In each case `.confirmPartial` offers "Save the rest" and "Cancel".
- **Nothing savable:** `.failed("Nothing Hippo can save was shared.", canSave: false)`.
- **Save:**
  - `userNote` is the trimmed comment, nil if empty.
  - `location` is `location(startedAt)`.
  - Then `store.capture(draft, partialPolicy: acceptPartial ? .acceptPartial : .rejectPartial)`.
  - Success: `intake.discard(captureID:)`, then `.saved`.
  - Errors map to:
    - `insufficientSpace` → "Not enough space on this iPhone. Nothing was saved."
    - `attachmentsFailed` → `.confirmPartial("{n} items couldn't be saved.")`
    - `emptyCapture` → "Nothing Hippo can save was shared."
    - anything else → "Hippo couldn't save this. Nothing was saved."
- **Cancel:** `intake.discard(captureID:)`.
